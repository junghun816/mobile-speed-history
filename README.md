# 🚴🏃 Pacer

GPS 기반 자전거·런닝 주행 기록 앱. 속도·거리·시간을 실시간으로 측정하고, 네이버 지도로 경로를 표시하며, 주행 기록을 분석·통계·목표 관리까지 제공한다.

Android / iOS 지원.

---

## 화면 구성

바텀 내비게이션 5탭 구조. `IndexedStack`으로 탭 전환 시 상태 유지.

### 🟦 속도계

자동차 계기판 스타일의 커스텀 원형 게이지.

- **자전거 / 런닝** 모드 전환 (마지막 선택 유지)
- 속도에 따라 게이지 색상 단계 변화 (파랑 → 초록 → 주황 → 빨강)
- 속도 보간 처리 — 0.2초마다 부드럽게 바늘 이동
- 속도 초과 알림 시 게이지·숫자 빨간색, 미달 알림 시 파란색으로 강조 (자전거 전용)
- 하단 통계 카드 (거리 / 시간 / 최고속도 / 평균속도 — 설정에서 표시 여부 선택)
- 주행 중 상단 알림 표시, 종료 시 자동 제거
- 백그라운드·잠금화면에서도 시간 정확히 측정 (시작 시각 기준 경과 계산)
- 자동 일시정지 중 배너 표시
- 주행 완료 팝업 — 거리 / 시간 / 최고속도 / 칼로리(체중 설정 시) + 메모 입력

**런닝 전용 기능**
- 케이던스 메트로놈 (목표 BPM 진동·소리)
- 음성 안내 TTS ("N킬로미터 완주, 페이스 X분 Y초")
- 목표 페이스 초과 시 진동 알림
- 1km 자동 랩 기록

### 🗺️ 지도

네이버 지도 기반 실시간 주행 화면.

- 앱 진입 시 현재 위치로 자동 이동
- 주행 중 실시간 경로를 선으로 표시
- 하단 거리 / 시간 / 최고속도 실시간 표시
- 현재 속도 뱃지 — 위치 드래그 이동 + 크기 조절 가능

### 📊 기록

6개 탭으로 세분화된 주행 분석.

| 탭 | 내용 |
|---|---|
| **평균** | 1회 평균 통계 + 전체 누적 통계 |
| **연도별** | 연도별 막대 그래프, 탭 시 월별 breakdown |
| **월별** | 월별 막대 그래프, 탭 시 달력 히트맵 + 주차별 통계 |
| **일별** | 기간 필터 + 요일별 평균, 탭 시 날짜별 목록 |
| **상세** | 날짜 선택 후 해당 날 주행 목록 + 달력 |
| **전체** | 연/월/일 필터, 정렬, 최고 기록 뱃지 |

- 기록 카드 탭 → 상세 팝업 (통계 / 메모 수정 / 경로 보기 / GPX 공유)
- 전체 탭에서 기록 삭제 가능

### 🎯 목표

별도 DB 없이 기존 기록 데이터만으로 동작.

- **거리 목표** — 올해 / 이번달 목표 거리 설정, 진행률 바 + 달성 시 체크 표시
- **도전 목표** — 최고속도 / 최장거리(1회) / 최장시간(1회) 목표 설정
- **주행 스트릭** — 현재 연속 주행일 / 역대 최장 스트릭 표시

### ⚙️ 설정

2단계 네비게이션 구조 (대메뉴 → 상세 화면).

| 항목 | 내용 |
|---|---|
| **주행** | 속도 측정 모드 / 자동 일시정지 / 최소 기록 거리·시간 / 단위(km·mph) / GPS 정확도 |
| **화면** | 주행 중 표시 항목 선택 / 속도계 시계 표시 |
| **알림** | 속도 초과·미달·거리 알림 — 팝업·진동·소리 각각 독립 제어 (자전거 전용) |
| **런닝** | 음성 안내 / 케이던스 BPM / 목표 페이스 |
| **지도** | 지도 스타일 / 경로 색상·두께 / 추적 모드 기본값 |
| **사용자** | 체중 (칼로리 계산에 사용) / 자전거 관리 (등록·수정·삭제) |
| **시스템** | 테마(Dark/Light) / 시작 탭 / 백업·내보내기 / 앱 정보 |

백업·내보내기 옵션: 공유 / 파일 저장 / 가져오기(중복 제외 병합) / GPX 내보내기(Strava 등 호환)

## 데이터 구조

```
ride_records
├── id            (자동증가)
├── year / month / day
├── totalDistance (km)
├── maxSpeed      (km/h)
├── avgSpeed      (km/h)
├── duration      (초)
├── pathPoints    ([{lat, lng}, ...] JSON)
├── memo          (선택)
├── createdAt     (ms epoch)
├── activityType  ('bike' | 'run')
└── lapSplits     ([{...}, ...] JSON, 런닝 랩 데이터)

bikes
├── id            (자동증가)
└── ...           (자전거 정보)
```

내부 저장 단위: 속도 **km/h**, 거리 **km**. 화면 표시 시점에만 mph·mi로 변환.

## 기타

- 뒤로가기 2번 → 앱 종료 (Android)
- 앱 시작 시 위치 권한 → 알림 권한 순서로 요청
- 스플래시: 검정 배경 + 속도계 아이콘
- DB 버전 관리로 스키마 변경 시 자동 마이그레이션 (현재 v6)
